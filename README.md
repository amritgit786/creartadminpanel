## ✨ Modules

| Module | Screens |
| :--- | :--- |
| **Dashboard** | Overview home page |
| **Employees** | Add employee · All employees |
| **Attendance** | Attendance list |
| **Leaves** | Leave requests · Leave info · Holidays |
| **Work shifts** | Add shift · List shifts |
| **Expenses** | Expense list |
| **Location masters** | States · Cities · Areas (add + list for each) |

## 🏗️ Structure

```
src/
├── Components/   # Layout, Header, Navbar, PageHeader, Footer, Dashboard
└── Pages/        # Employee, Attendance, Leaves, WorkShifts, Expanses, State, City, Area, Home
```

- Shared **Layout** component wraps every page with header, navigation and footer
- Client-side routing with **React Router**
- Forms and data tables built as reusable React components on top of Tabler styles

## 🚀 Getting started

```bash
git clone https://github.com/amritgit786/creartadminpanel.git
cd creartadminpanel
npm install
npm run dev
```
